# 项目搭建

## 环境要求

- Node.js >= v24.10.0
- pnpm >= v10.19.0

安装依赖：

```bash
pnpm add langchain @langchain/core @langchain/openai dotenv @inquirer/prompts
```

查看 [LangChain 官方文档](https://docs.langchain.com/oss/javascript/langchain/overview)，
了解更多关于 LangChain 的信息。

## 项目新建

新建 `src/01-chat.js` 文件，用于测试 LangChain。复制以下代码：

```js
import { ChatOpenAI } from '@langchain/openai'
import { config } from 'dotenv'
import { input } from '@inquirer/prompts'

// 加载环境变量
config()

const chatModel = new ChatOpenAI({
  // 模型名
  model: 'qwen3.7-plus',
  // 额外传递给模型的参数
  modelKwargs: {
    // 关闭深度思考
    enable_thinking: false,
  },
  configuration: {
    // 模型厂商提供的 baseURL
    baseURL: '你自己的 baseURL',
    // 你自己的 API KEY
    apiKey: '你的 API KEY，别偷看我的',
  },
})

// 在命令行里输入文本
const content = await input({ message: '你 >' })

// 给模型发送消息
const result = await chatModel.invoke([
  {
    role: 'user',
    // 把命令行里面你叽里呱啦输入的内容发送给大模型
    content: content,
  },
])

console.log(result.content) // 看到模型叽里呱啦的输出
```

baseUrl 和 apiKey 是模型厂商提供的，需要替换为自己的值。

![baseUrl](../../../../images/practice/ai/AI%20Agent+智能大屏设计器/baseUrl.png)

- OpenAI compatible：OpenAI 格式的模型，支持 LangChain 提供的 API。
- Anthropic：Anthropic 格式的模型，支持 LangChain 提供的 API。

其中，导入的 `ChatOpenAI` 构造函数用于创建一个 ChatOpenAI 实例，只要模型支持 OpenAI 格式，就能用这个构造函数来打通。

`config` 函数用于加载环境变量，确保在运行时能够使用到 `.env` 文件中的变量。

`input` 函数用于在命令行里获取用户输入。前面添加 `await` 关键字，**是因为用户输入是异步的**。

`invoke` 函数用于向大模型发送一次消息请求，并等待模型返回结果。调用 `invoke` 后，它会自动帮我们的 `url` 拼接后续路径 `/chat/completions`。

| API                         | 作用                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------- |
| ChatOpenAI                  | LangChain 提供的模型构造函数，用来按 OpenAI API 兼容接口创建一个可调用的大模型对象。 |
| `config`                    | `dotenv` 提供的函数，用来加载 `.env` 文件中的环境变量。                              |
| `input`                     | 在命令行显示输入提示，等待用户输入文本。                                             |
| `chatModel.invoke([...])`   | 向大模型发送一次消息请求，并等待模型返回结果。                                       |
| `{ role: 'user', content }` | `{ role: 'user', content }`                                                          | 表示一条用户消息，告诉模型这段内容来自用户。 |

为了启动项目，需要回到 `package.json` 文件目录，添加以下命令：

```json
"scripts": {
    "dev": "node src/01-chat.js", // [!code ++]
    "test": "echo \"Error: no test specified\" && exit 1"
},
```

## key 存储

apikey 不能直接明文存储，存放到 `.env` 文件中。

```js
import { ChatOpenAI } from '@langchain/openai'
import { config } from 'dotenv'
import { input } from '@inquirer/prompts'

// 加载环境变量
config()

const chatModel = new ChatOpenAI({
  // 模型名
  model: 'qwen-plus',
  // 额外传递给模型的参数
  modelKwargs: {
    // 开启深度思考
    enable_thinking: true,
  },
  configuration: {
    // 模型厂商提供的 baseURL
    baseURL: process.env.AI_BASE_URL, // [!code focus]
    // 你自己的 API KEY
    apiKey: process.env.AI_API_KEY, // [!code focus]
  },
})

// 在命令行里输入文本
const content = await input({ message: '你 >' })

// 给模型发送消息
const result = await chatModel.invoke([
  {
    role: 'user',
    // 把命令行里面你叽里呱啦输入的内容发送给大模型
    content: content,
  },
])

console.log(result) // 看到模型叽里呱啦的输出
```

```json
{
  "semi": false,
```
