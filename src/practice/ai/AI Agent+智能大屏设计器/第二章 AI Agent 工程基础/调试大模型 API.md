# 购买调试大模型 API

## 登录

先打开这个网站：[阿里百炼](https://bailian.console.aliyun.com/) 登录。

类似的模型购买平台有很多，比如 硅基流动、 deepseek，不一一介绍了，我们的课程就使用 阿里百炼。

## 模型

左上角 nav 菜单点击“模型”，左下角点击“用量&费用”。

![用量费用](../../../../images/practice/ai/AI%20Agent+智能大屏设计器/用量费用.png)

查看是否有免费额度，如果有可以免费使用；没有则需要点击右上角头像，选择“充值汇款”购买。

充值完或者有免费不需要充值，返回上一页模块，点击“API key”，右上角点击“创建API key”按钮，描述随意，然后**不要关闭弹窗，后续无法再重新打开，建议截图保存并复制一份保存到文档里**。

## 调试

然后关闭弹窗，点击上方nav菜单的“API 参考”，点击左侧的“OpenAI兼容-Chat”，还可以调试，只需要粘贴刚刚保存的 API key即可。

![模型API参考](../../../../images/practice/ai/AI%20Agent+智能大屏设计器/模型API参考.png)

请求体已经配置好了，其中：

- model：模型名称，这里使用的是 `qwen-plus`。
- messages：消息列表，发送给模型的消息。
  - role：用户角色，`system`是系统， `user` 是用户角色。
  - content：用户的消息。

点击发送请求后就可查看调试结果。

![调试结果](../../../../images/practice/ai/AI%20Agent+智能大屏设计器/调试结果.png)

## 注意事项

要值得注意的是，大模型 是没有记忆功能的。每一次的对话都是独立的，大模型是不会记住之前的对话内容的。

那么之前使用的 deepseek、豆包都是怎么记住的呢？

其实是通过**上下文传递**的方式实现的。每次用户发送消息时，都会把之前的对话内容也保存到 `message` 数组里传递给模型，模型会根据历史消息上下文来生成回复。

还能切换其他模型来做测试，这里不做过多赘述。

后续还能体验图片输入（注意图片路径不能去谷歌搜索），工具调用等功能。
