# 前端工具卡片

部分场景下 <word text="LLM" /> 需要给用户返回预制卡片，让用户完成选择操作。例如：

1. 我要点外卖 → 展示外卖选择 <word text="UI" /> 组件 → 选择后发送消息给 AI → AI 完成订购
2. 我要买衣服 → 展示衣服选择 <word text="UI" /> 组件

工具不限于服务器端执行逻辑，也可以是让前端展示预制 <word text="UI" /> 卡片，即前端工具卡片。

## 卡片逻辑

目前没有专门定义前端卡片的标准规范，采用以下变通方案：

1. 定义前端展示类 <word text="Function Tool" />，声明需要前端展示的内容
2. 代码层检测到前端展示 <word text="Function Tool" /> 后，下发消息给前端，`role` 保持 `tool`，附加自定义 `cardName` 属性

```js [tools.js]
const toolList = [
  // ...
  {
    type: 'function',
    function: {
      name: 'wm_card',
      description: '用户点外卖时，调用此工具让前端展示一个外卖选择的ui结构',
      paramenters: {
        kind: {
          type: 'string',
          description: '外卖的种类'
        }
      }
    }
  }
]
```
